# Video Factory

A cloud-only, free-first short-video generator. It runs on GitHub Actions; no Termux, local installation, API key, or paid generation service is required for the included workflow.

## Video styles

Choose a visual template from the GitHub Actions form:

- **Educational** — clean cards for lessons, explainers and exam topics.
- **Cinematic** — darker, dramatic title and caption layout.
- **News** — red news/explainer styling for current-affairs summaries.
- **Facts** — numbered fact-card layout for list-style shorts.
- **Quote** — centered typography for quotes and short messages.

All templates render a vertical 9:16 MP4 (1080 × 1920) with a subtle zoom movement, scene-by-scene text, progress indicator, and an original ambient audio bed.

## Hindi and English narration

The workflow first attempts a free, online neural voice through the open-source \`edge-tts\` Python package. Hindi offers Swara (female) and Madhur (male); English uses neural English voices. No API key is configured in this repository. The service requires internet access and may be rate-limited, changed, or unavailable; when it fails, the renderer falls back to offline eSpeak NG. The fallback is robotic, not a neural voice.

## Background visuals and licensing

Leave **Wikimedia Commons background search** empty to use graphics drawn by the renderer. Enter a subject such as \`Indian Parliament\`, \`Himalayan mountains\`, or \`solar system\` to try to find a related Commons image.

The image downloader accepts only Public Domain, CC0, CC BY and CC BY-SA-style licenses, and rejects NonCommercial and NoDerivatives labels. It writes the image author, license and source page to \`credits.txt\` and adds a short credit to the rendered scene. Search results may be unavailable or may not contain a suitable license; the renderer then falls back to its own generated graphics.

**Important:** these visuals are not generated by an AI image model. This free path uses renderer-created graphics or externally sourced, license-filtered Commons images. No paid image-generation API or GPU is used.

## Create a video

1. Open the repository's **Actions** tab.
2. Select **Generate Short Video** → **Run workflow**.
3. Enter a title and narration, then choose language, template, voice gender and duration.
4. Optionally enter a Wikimedia Commons visual search query.
5. Run the workflow. When complete, open the run and download the **video-factory-output** artifact.

The artifact contains:
- \`video-factory-short.mp4\` — finished video with narration and ambient audio.
- \`video-factory-short.srt\` — subtitle file.
- \`credits.txt\` — voice mode and image attribution/licensing details.

Narration works best as a few short sentences. The renderer distributes the text across scenes automatically.

## Run tests

The GitHub workflow runs unit tests before rendering. The tests cover Hindi/English sentence splitting, scene grouping, supported templates, subtitle timestamps and the Commons license filter.

## Repository layout

- \`engine/render_video.py\` — templates, graphics, Commons image lookup, narration, audio and FFmpeg rendering.
- \`tests/\` — unit tests.
- \`.github/workflows/generate-video.yml\` — cloud workflow and artifact upload.
- \`examples/\` — sample Hindi and English inputs.

## Limits

GitHub Actions usage is subject to account quotas, repository settings, runner availability and GitHub's current policies. Artifact retention is seven days. Neural TTS depends on a third-party online service and is not guaranteed to remain unlimited or available. The offline fallback is lower quality. Commons search depends on network access and available compatible licenses. This is a free, CPU-based motion-graphics and sourced-image workflow, not a text-to-video diffusion model; it does not promise AI-generated cinematic footage, a free GPU, or automatic publishing to YouTube/social platforms.
